# Design Philosophy

## Core Principles

1. **MCP Protocol Correctness**: Every tool response follows the MCP SDK contract. Tool handlers return `{ content: [{ type: "text", text }], isError }`. Schema validation via Zod runs before any execution logic.

2. **Stdio Safety**: The MCP server communicates over stdio. Never use `console.log` in server code -- it corrupts the MCP transport. Use `process.stderr.write` for diagnostics.

3. **Graceful Degradation**: If Codex CLI is unavailable, return a clear error message with installation instructions. If a session file is corrupt, skip it with a warning and continue loading valid sessions.

4. **Atomic Persistence**: Session files are written to `.tmp` then renamed. This prevents partial writes from corrupting session state on crash or timeout.

5. **POSIX Portability**: Hook scripts must work on macOS and Linux without bash-specific features. No `grep -P`, no arrays, no process substitution.

## Source Structure

| Directory | Contents | Modification Rule |
|-----------|----------|-------------------|
| `src/codex/` | MCP server, schemas, executor, sessions, parser, CLI detection | Core runtime -- changes require MCP protocol awareness |
| `src/types.ts` | Shared type definitions (CodexExecResult, SessionEntry, event types) | Interface changes affect all modules |
| `agents/` | Agent markdown definitions (Claude-native + Codex delegation) | Follow agent template structure |
| `skills/` | SKILL.md files for slash commands | Frontmatter must match plugin.json |
| `hooks/` | Hook scripts + hooks.json config | POSIX-portable, timeout-safe |
| `bridge/` | Bundled output (coral-codex.cjs) | Generated by build -- do not edit directly |
| `docs/` | Architecture, module docs, guides | Update when architecture or API surface changes. Do not duplicate source artifacts. |

## Module Structure

Dependency direction is strict: `server.ts` is the composition root (wiring only). Lower modules never import from upper modules. See `docs/architecture.md` for the current dependency graph.
